NARUTO SHINOBI GIF REPOSITORY SLOTS
================================================================================

To add animated GIFs into your profile:
1. Search on https://giphy.com or https://tenor.com
2. Use "Copy GIF Link" to download the .gif file (keep each file under 4 MB)
3. Name and place the GIF file directly in this folder (`assets/gifs/`):

SLOTS:
- hero.gif            -> Replaces top banner animation
- sharingan.gif       -> Replaces sharingan divider
- kurama.gif          -> Replaces Kurama blazing eyes
- shadow-clones.gif   -> Replaces footer clones team
- final-valley.gif    -> Replaces Campus Twin 3D showcase demo

Note: The README uses custom hand-drawn animated SVGs for all slots by default.
Whenever any of these GIF files exist in this folder, you can swap the reference in README.md!
